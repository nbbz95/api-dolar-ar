API Dólar AR

API pública, gratuita y sin servidor con las cotizaciones del dólar en Argentina. Se regenera todos los días con GitHub Actions y se sirve como JSON estático desde GitHub Pages.

Endpoints

  • GET /v1/dolares.json: cotización actual de cada casa.
  • GET /v1/brecha.json: brecha porcentual contra el oficial.
  • GET /v1/historico/{casa}.json: serie diaria completa.
  • GET /v1/resumen/{casa}.json: último valor y variación a 7, 30 y 365 días.
  • GET /v1/index.json: casas disponibles y fecha de generación.

Ejemplo

fetch('https://nbbz95.github.io/api-dolar-ar/v1/dolares.json')
  .then(r => r.json())
  .then(console.log)
